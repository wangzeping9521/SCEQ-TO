# 变电站土建工程量计算系统

单文件 HTML 工程量计算工具，面向变电站土建工程（设备基础/端子箱基础等），覆盖**土方开挖、回填、余土外运、砼基础、钢筋**五大项工程量计算，清单项目与计算规则引用电力行业清单规范，支持**自动生成 Excel 工程量计算书**与**图纸上传识别辅助**。

## 功能特性

- **土方开挖**：矩形基坑放坡（棱台公式）、沟槽放坡（梯形截面×长）；沟槽/基坑自动判定；放坡系数、工作面宽度、松实系数按 DL/T 5341-2021 表 C.1.1-2/3/4 取值。
- **回填与外运**：回填 = 开挖 − 垫层 − 基础埋入（天然方）；土方运输（SA09）按天然密实体积、余方弃置（SA24）按实际堆积状态（松方）计量；自动估算运土车次。
- **砼基础**：垫层、独立基础/一般设备基础/条型基础体积计算，含定额损耗率（默认 1.5%）需方量。
- **钢筋计算**：按组添加（底板双向筋/插筋/箍筋等），根数 = ⌊(布筋范围−2c)/间距⌋+1，理论重量 0.00617×d²，自动汇总吨位。
- **工程量清单汇总**：项目编码、名称、单位、工程量、计算规则自动生成，编码按 **DL/T 5341-2021《变电工程》附录C（施工图阶段）** SA/SE 体系。
- **导出 Excel 计算书**：一键生成多工作表 .xlsx（清单汇总 / 土方开挖 / 回填外运 / 砼基础 / 钢筋 / 编制依据）。
- **图纸上传与识别辅助**：支持 JPG/PNG/PDF 上传预览；本地 OCR（Tesseract，数据不出本机）；可选接入自己的 AI 视觉接口自动提取参数填入。
- **打印/导出 PDF 计算书**：浏览器打印即可输出带完整计算式的计算书。

## 清单编码依据（DL/T 5341-2021 附录C）

| 项目 | 编码 | 说明 |
|---|---|---|
| 挖基坑/沟槽土方 | SA05 / SA04 | 基础（含垫层）尺寸+工作面+放坡宽度×开挖深度 |
| 回填方 | SA20 | 按设计图示尺寸以体积计算 |
| 土方运输 | SA09 | 挖方总体积−回填方总体积，按天然密实体积 |
| 余方弃置 | SA24 | 按实际堆积状态（松方）以体积计算 |
| 现浇混凝土垫层 | SE01 | 按设计图示尺寸以体积计算 |
| 独立/一般设备/条型基础 | SE03 / SE09 / SE02 | 按基础形式自动对应 |
| 钢筋制作安装 | SE76 | 设计长度×单位理论质量（结构+构造+连接用量） |

主要参数取值：放坡系数表 C.1.1-3（普土Ⅰ~Ⅱ类起点≥1.2m、坚土Ⅲ~Ⅳ类起点＞1.8m），工作面宽度表 C.1.1-4（混凝土支模 300mm 等），土石方松实系数表 C.1.1-2（土方松散 1.33）。

## 使用说明

1. 用浏览器（推荐 Chrome / Edge）直接打开 `变电站土建工程量计算系统.html`，无需安装。
2. 在「土方开挖」页输入基础形式与尺寸参数（默认示例为图纸参数，可按实际修改）。
3. 查看「回填外运」「砼基础」「钢筋计算」页联动结果，按需增删钢筋组。
4. 「清单汇总」页核对项目编码与工程量，可**导出 Excel 计算书**、打印/导出 PDF、复制清单文本。
5. 「图纸识别」页可上传图纸预览；点「开始 OCR 识别」本地识别文字数字；或配置自己的 AI 接口（API 地址/Key/模型名）点「AI 识别并填入参数」自动回填。

> 说明：本地 OCR 与图纸预览均在浏览器内完成，数据不出本机；AI 视觉识别会将图纸上传到你**自己配置**的 AI 服务，请勿上传涉密图纸。

## 部署到 GitHub Pages

1. 新建仓库，上传 `变电站土建工程量计算系统.html`（可选同时上传 `_shots` 截图目录用于 README 展示）。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存。
3. 等待 1~2 分钟后访问 `https://<用户名>.github.io/<仓库名>/` 即可在线使用。
